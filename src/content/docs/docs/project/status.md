**Atomic Flow is currently in pre-alpha development.**

The initial work focuses on the shared vocabulary, the TypeScript execution model, and testing strategies for partial failures and recovery. Public APIs and behavior are expected to evolve.

## What exists

- [Project repository](https://github.com/atomic-flow-dev/atomic-flow) for cross-language direction and specifications.
- [TypeScript repository](https://github.com/atomic-flow-dev/atomic-flow-ts) with the Core and Failure Lab workspace skeleton.
- [Website repository](https://github.com/atomic-flow-dev/atomic-flow-site) containing the project's documentation website.

## What is still planned

- Finalized language-independent behavior and conformance criteria.
- Implemented, documented TypeScript APIs.
- Failure and recovery test coverage.
- Public alpha release and package installation instructions.
- Later assessment of other language implementations.

## Contributions

The repositories are public, but external contributions are temporarily restricted while core architectural decisions are made.

The [roadmap](/roadmap/) describes the current direction. It is not a binding release schedule.
